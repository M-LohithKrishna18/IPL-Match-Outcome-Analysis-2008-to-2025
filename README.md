# IPL Match Outcome Analysis (2008 to 2025)

Exploratory data analysis on 1,169 IPL matches across 18 seasons of IPL cricket.

## What I Analyzed
- Does winning the toss actually help win the match?
- Which franchises have the best win percentage across all seasons?
- How has the number of matches evolved season by season?
- Do teams prefer to bat or field after winning the toss?
- How do top teams like MI, CSK, KKR and RCB compare on total wins?

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Kaggle Notebooks

## Dataset
IPL Complete Dataset (2008 to 2025) sourced from Kaggle
278,205 balls | 1,169 matches | 18 seasons | 19 teams | 59 venues

## Key Findings
- Toss winners win approximately 51% of matches showing toss has minimal impact
- Mumbai Indians and Chennai Super Kings lead all franchises in win percentage
- IPL has grown significantly in matches per season over 18 years
- Teams heavily prefer fielding first after winning the toss in modern IPL
